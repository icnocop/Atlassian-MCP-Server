The tools are grouped into toolsets, which the `ATLASSIAN_TOOLSETS` environment variable enables. Read-only tools change nothing; they are the only tools available when `ATLASSIAN_READ_ONLY` is `true`.

This file is generated by `build/Update-ToolsDoc.ps1`. It lists 133 tools.
